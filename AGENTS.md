# Instrucciones del proyecto

- Después de completar cualquier cambio al sitio —código, contenido, diseño, configuración o base de datos— ejecuta las validaciones pertinentes y vuelve a desplegar la versión terminada en el Site existente.
- Confirma que el despliegue finalizó correctamente y entrega la URL de producción.
- Conserva el acceso público del sitio y la base de datos D1, salvo que el usuario pida explícitamente cambiarlos.
- Las consultas o revisiones que no modifiquen el proyecto no requieren un nuevo despliegue.
